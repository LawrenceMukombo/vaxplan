# Supervision Tools Walkthrough

## 1. Module Purpose
Facilitates Integrated Supportive Supervision (ISS) through digital checklists and automated scoring.

## 2. Who Uses It
- **District Managers:** Conduct visits.
- **Provincial Coordinators:** View aggregate scores.

## 3. Main Screens and Navigation
- **Supervision Schedule:** List of planned visits.
- **Checklist Runner:** Offline-capable form for data entry during a visit.

## 4. Key Actions
### 4.1. Conducting a Visit
1. Open the scheduled visit on your tablet (can be done offline).
2. Answer the checklist questions (e.g., "Is the fridge temperature between 2-8°C?").
3. Add action points for any failures.
4. Sync when back online.

## 5. Permissions and RBAC
- Facility users can view their own scores but cannot edit the checklists.

## 6. Troubleshooting
> **Baby steps:** If the checklist won't submit offline, check that all mandatory fields have been answered.
