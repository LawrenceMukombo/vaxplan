# Polygon Drawing Walkthrough

## 1. Module Purpose
Provides the tools to digitally trace the physical boundaries of a health facility's catchment area.

## 2. Who Uses It
- **Facility Users:** To define their own service area.
- **GIS Specialists:** To resolve conflicts.

## 3. Main Screens and Navigation
- Found within **Facilities -> Detail View -> Polygon Drawing Tab**.

## 4. Key Actions
### 4.1. Drawing a Catchment
1. Click the "Draw Polygon" icon on the Leaflet toolbar.
2. Click points on the map to trace the boundary.
3. Click the first point to close the shape.
4. Click **Save**.

## 5. Permissions and RBAC
- Facility Users can only draw for their assigned facility.

## 6. Troubleshooting
> **Baby steps:** If the polygon turns red, it means it overlaps with a neighboring facility. You must adjust the borders so they do not overlap.
