# Research Module Walkthrough

## 1. Module Purpose
A central repository for implementation learnings, pilot tracking, and operational research documents.

## 2. Who Uses It
- **National Admins:** Upload official policies.
- **Partners / Researchers:** Download datasets and read pilot results.

## 3. Main Screens and Navigation
- **Research Hub:** Searchable library interface.

## 4. Key Actions
### 4.1. Uploading a Document
1. Click **Upload Document**.
2. Select the file, add metadata tags (e.g., "Pilot", "Zero-Dose").
3. Submit.

## 5. Permissions and RBAC
- Only National Admins and specific "Researcher" roles can upload. Everyone else has read-only access.

## 6. Troubleshooting
> **Baby steps:** Ensure your file is under the 10MB limit and in a supported format (PDF, DOCX).
