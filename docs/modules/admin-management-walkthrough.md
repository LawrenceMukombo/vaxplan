# Admin Management Walkthrough

## 1. Module Purpose
Configures the country's Tenant settings, user access, and global parameters (like the Vaccine Schedule).

## 2. Who Uses It
- **National Admins**

## 3. Main Screens and Navigation
- **Users & Roles:** RBAC management.
- **System Settings:** Vaccine schedules, notification settings.
- **Audit Logs:** Security tracking.

## 4. Key Actions
### 4.1. Reviewing Audit Logs
1. Navigate to **Administration -> Audit Logs**.
2. Filter by user or date.
3. Review modifications to critical records (e.g., population denominator overrides).

## 5. Permissions and RBAC
- Strictly limited to the National Admin role.

## 6. Troubleshooting
> **Baby steps:** If a user complains they don't have access to a specific district, check their user profile to ensure they are assigned to the correct geographic level.
